# Design Issue #66 (v1)

> Architektur-Loop (`anthropic/claude-opus-5.5`, Runde 1); ein Pruefer anderer Modellfamilie nimmt es ab, bevor Dev beginnt. Dev folgt diesem Weg.

## Loesungsweg

In findings_report/render.py kommt eine Hilfsfunktion _ort_html(ort) hinzu. Sie gibt bei ort.startswith("https://") (exakt, case-sensitiv) den String '<a href="' + html.escape(ort, quote=True) + '">' + html.escape(ort, quote=True) + '</a>' zurueck, sonst nur html.escape(ort, quote=True). An der Stelle, an der der Befund-Ort bisher escaped ausgegeben wird (eingefuehrt mit #45), wird der bisherige Escape-Aufruf durch _ort_html(ort) ersetzt; Umgebung, Klassen und Position bleiben gleich. Befunde ohne ort durchlaufen den bisherigen Zweig unveraendert, es werden kein CSS und keine anderen Texte geaendert.

## Dateien

- `findings_report/render.py`: Neue Funktion _ort_html(ort) mit https://-Pruefung und html.escape(quote=True) fuer href und Linktext; die bisherige Ausgabe des ort nutzt diese Funktion, alles andere bleibt unveraendert.

## Blast-Radius

Nur die HTML-Ausgabe von Befunden mit ort; Validierung, CLI-Ausgabe und Befunde ohne ort sind nicht betroffen.
