# Design Issue #58 (v1)

> Architektur-Loop (`anthropic/claude-opus-5.5`, Runde 2); ein Pruefer anderer Modellfamilie nimmt es ab, bevor Dev beginnt. Dev folgt diesem Weg.

## Loesungsweg

In findings_report/__main__.py in der Einstiegsfunktion (main bzw. dem Block, der sys.argv auswertet) vor der bestehenden Pruefung der Argumentzahl einen Zweig einfuegen: Ist genau ein Argument vorhanden und lautet es '--help', wird die bestehende Verwendungszeile (dieselbe Zeichenkette, die bei falscher Argumentzahl auf stderr geht und mit 'Verwendung:' beginnt sowie '<bericht.json>' enthaelt) per print auf stdout ausgegeben, und die Funktion endet mit Exit-Code 0, ohne etwas auf stderr zu schreiben. Liegt die Zeile bisher nur inline vor, wird sie in eine Modulkonstante (z.B. USAGE) gezogen und an beiden Stellen unveraendert verwendet. Der Fall ohne Argumente (Exit 2, eine Verwendungszeile auf stderr) sowie Pruefung und HTML-Ausgabe bleiben unveraendert; README und andere Dateien werden nicht angefasst.

## Dateien

- `findings_report/__main__.py`: Vor der Argumentzahl-Pruefung wird '--help' als einziges Argument erkannt, die unveraenderte Verwendungszeile (ggf. als Konstante USAGE herausgezogen) auf stdout ausgegeben und mit Exit-Code 0 beendet.

## Blast-Radius

Nur der CLI-Einstieg; eine Datei namens --help kann nicht mehr als Bericht uebergeben werden. Pruefung, HTML-Ausgabe und Fehlerpfade bleiben gleich.
