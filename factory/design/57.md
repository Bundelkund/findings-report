# Design Issue #57 (v1)

> Architektur-Loop (`anthropic/claude-opus-5.5`, Runde 2); ein Pruefer anderer Modellfamilie nimmt es ab, bevor Dev beginnt. Dev folgt diesem Weg.

## Loesungsweg

In findings_report/__main__.py wird ganz am Anfang der Einstiegsfunktion (bzw. des if __name__ == '__main__'-Blocks), vor jeder bestehenden Argument- oder Dateiverarbeitung, geprueft, ob sys.argv[1:] genau ['--version'] ist. In diesem Fall wird mit 'from findings_report import __version__' die vorhandene Version gelesen, per print(f'findings_report {__version__}') genau eine Zeile auf stdout geschrieben und mit sys.exit(0) bzw. return 0 beendet, ohne etwas auf stderr auszugeben. Alle anderen Aufrufe laufen unveraendert durch den bestehenden Code. __init__.py und README bleiben unangetastet.

## Dateien

- `findings_report/__main__.py`: Frueher Sonderfall: ist sys.argv[1:] == ['--version'], wird 'findings_report ' plus __version__ aus dem Paket auf stdout gedruckt und mit Exit-Code 0 beendet; der restliche Ablauf bleibt unveraendert.

## Blast-Radius

Nur der Kommandozeilen-Einstieg; Aufrufe mit Berichtsdatei und HTML-Ausgabe laufen unveraendert durch den bestehenden Pfad. Keine Daten betroffen.
