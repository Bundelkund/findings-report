# Spec Issue #55: Paket meldet seine Version (__version__)

> Erzeugt vom Requirement-Loop (`xiaomi/mimo-v2.6-pro`, Runde 1); jedes AK hat der Testing-Pruefer auf Pruefbarkeit geprueft, bevor Tests entstehen.

## Ziel

Das Paket findings_report stellt eine Konstante __version__ mit dem Wert '0.1.0' bereit, die per Import abfragbar ist; alles andere bleibt unveraendert.

## Nicht-Ziele

- Kommandozeile bleibt unveraendert
- HTML-Ausgabe bleibt unveraendert

## Akzeptanzkriterien

AK1: python3 -c "import findings_report; print(findings_report.__version__)" gibt genau `0.1.0` aus (Exit 0).
Pruefung: Ein unittest fuehrt diesen Befehl per subprocess im Repo-Wurzelverzeichnis aus und vergleicht stdout.strip() mit '0.1.0' und returncode mit 0.
AK2: findings_report.__version__ ist vom Typ Text (`str`).
Pruefung: Ein unittest importiert findings_report und stellt per assertIsInstance(findings_report.__version__, str) fest, dass der Wert ein str ist.
